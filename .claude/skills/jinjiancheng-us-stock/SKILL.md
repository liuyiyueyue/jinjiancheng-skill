## 核心操作技术

### 1. 金字塔加仓法（下跌时摊低成本）

**原理**：越跌越买，份额递增

**示例**：
```
100元买30股
90元买50股
80元买80股
70元买120股
→ 成本从100降到79.64元
→ 只要反弹到80元就开始盈利
```

**要点**：
- 必须选对股票（基本面不能恶化）
- 预留足够弹药，分批建仓
- "不要错过任何一次基本面没有恶化，而是由恐慌情绪主导的下跌"

### 2. 倒金字塔卖出法（上涨时锁定利润）

**原理**：越涨卖得越多

**示例**：
```
110元卖30股（先收回部分成本）
120元卖50股
130元卖80股
→ 先收回本金，逐步做成负成本
→ 剩余的利润继续持有，跌了也不心疼
```

### 3. 做T降成本

**正T操作**（先买后卖）：
- 下跌时买入 → 反弹时卖出
- 适合抄底过程

**反T操作**（先卖后买）：
- 预判下跌先卖出 → 低位再买回
- 适合高位减持

**要点**：
- **留够底仓**（50%底仓 + 50%做T）
- 底仓中长期持有不动
- 做T部分：25-30%逢高先出，后续继续减持
- 需要一定技术水平，不要轻易尝试

**金渐成的做T案例**（英伟达）：
```
90美元买入1万股：
- 5000股底仓（不动）
- 5000股做T：
  107美元卖2500股（25%）
  122美元卖500股
  135美元卖500股
  145美元卖1500股
→ 底仓成本大幅降低，甚至负成本
```

### 4. 负成本/低成本策略

**目标**：持股成本归零，甚至为负

**方法**：
1. 上涨时逢高减仓，收回成本和部分利润
2. 下跌时用金字塔加仓法摊低成本
3. 配合做T，进一步降低成本

**好处**：
- 账面剩余全是浮盈，心态轻松
- 套出的资金可以操作其他股票
- 长期持有多个负成本优质股

**金渐成的话**：
> "做低成本/负成本，看起来像是不断卖飞了，其实不然。"
> "持股做负成本，资金可以继续去操作其他个股，长此以往，持有的负成本优质个股会越来越多。"

### 5. 仓位管理

**永远不满仓**：
- 一般7-7.5成仓
- **最少留足30%备用金**
- 极个别情况8成仓

**原因**：
- 保持流动性，应对突发情况
- 下跌时有弹药加仓
- 避免被动套牢

## 投资理念

### 长线 vs 短线

**金渐成的选择**：
- **主做长线**：美股七巨头、消费龙头、医药龙头、茅台、腾讯
- **偶做短线**：波段套利（如MSTR）

**原则**：
- 美股的正确投资方式是中长期持有
- 短线达到预期就撤，不要贪心
- 中长线看好就不要做波段，容易卖飞
- **长期投资+价值投资，更适合普通人**

### 耐心是关键

**金渐成的话**：
> "做投资，要做个猎人。除了资金，要有耐心和勇气。"
> "猎人狩猎，最长的时间是花在潜伏上，开枪只是一瞬间的功夫。"
> "不要毛毛躁躁，上蹿下跳，那种只会是被狙的猎物。"

### 推荐的资产配置

**适合大多数普通人的进取型**：
- 20% 重流动性的短期
- 50% 重收益率和现金流的中期
- 30% 低风险的长期
- 也就是"80-20"（80%稳健型/防守型，20%进取型）

**适合大多数普通人的稳健型**：
- 30% 重流动性的短期
- 20-30% 重收益率和现金流的中期
- 40-50% 低风险的长期
