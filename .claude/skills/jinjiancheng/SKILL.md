## 查证文章

材料合计437篇，覆盖 **2022-11-05—2026-09-29**，分为两处：

- 根目录 `jinjiancheng_knowledge_base.json` 收录375篇，止于2026-04-29；现有命令行检索使用这个索引。
- `金渐成-历史文章-离线版/` 已补入2026-05-04—2026-09-29的62篇HTML。读取新文章时直接查离线文件，不能因旧索引搜不到就说没有材料。

旧文章日期使用库内 `publish_time`；新归档沿用标题目录及HTML标注，不自行推定时区或精确交易日。更早的离线文件名不等于有可用正文。

查截至2026-04-29的已索引文章，在项目根目录执行：

```bash
# 按关键词查全文，并补充与主题有关的已核对摘录
python3 jinjiancheng_grounding.py "中国平安"

# 阅读来源索引中的完整文章，无需模型 API
python3 jinjiancheng_grounding.py --source S04 --full

# 历史时点：只读取不晚于该日期的材料
python3 jinjiancheng_grounding.py "茅台" --as-of 2023-12-31
```

脚本位置是项目根目录；从本 skill 目录出发为 `../../../jinjiancheng_grounding.py`。不要假定宿主当前工作目录就在仓库。知识库及来源索引由脚本按自身位置加载。

S01—S18指向 [sources.json](references/sources.json)，可用上述命令读取全文；S19—S35指向 [recent-sources.json](references/recent-sources.json)，先读其中与问题相关的摘录，再按 `file_path` 读取离线HTML的 `#js_content` 正文。新来源编号不适用旧CLI的 `--source`。

两份来源文件都是精选核对材料，不是完整主题索引。关于“最后一次”“一直”“从不”的问题，要同时检索旧知识库与新增HTML并核对账户、时间和后续行动。搜索新归档可从 `金渐成-历史文章-离线版/2026-0[5-9]*` 目录定位，过滤发布日期后再读正文；不要仅搜索标题。未找到后续记录时说“收录材料未找到后续更新”。

2026年5—9月的新材料已纳入框架和时间线：需求与风险适配、低频持有、腾讯补仓、账户配比、印度与台湾持仓退出、买房等待条件、基金选择和学习方法。6—9月多篇文章说明下架旧文、减少披露；未再披露不能证明持仓未变，也不能据此推断清仓。

不要只看标题或文章开头。观点、反例、退出理由可能出现在后半段。关键词命中只用于找材料，不代表该材料足以支持答案。引用前阅读相关段落的上下文；旧来源可用 `--source … --full`，新来源直接读HTML正文。

若用户指定“截至某日”，先按日期筛选原文；参考文档中的后来结论仅用于定位材料，不得进入该历史时点的回答。先前对话中的未来信息也不能倒灌。文章发布时间与文中回顾的交易时间分开说明。

## 作答

先回答用户最关心的问题，再给必要的原文依据、判断条件和不确定性。简单问题无需展开全部投资流程。需要套用到用户处境时，区分原文、概括和分析推演。

历史事实注明文章标题与日期；有可用路径时附原文路径。引用只覆盖材料实际支持的主张。没有依据的价格、比例、个人持仓或“名言”不补写。

允许说不知道，也允许指出作者自述的局限。作者的收益、预测命中和交易记录属于文章自述，不能据此宣传已验证的成功率。
