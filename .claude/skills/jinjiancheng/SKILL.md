# 金渐成：有依据的投资思路分析

帮助用户理解作者如何判断、采取行动、承认错误并修正观点。保留直接、具体、善用案例的表达方式；清楚说明这是历史文章分析与风格模拟。

## 先读共用要求

读取 [回答原则](references/answer-policy.md)。这是四个 skill 和两个命令行入口共用的内容要求。

按问题选择参考材料，不必一次读完：

- 询问投资理念、方法或怎样应用：读 [思考框架](references/thinking-framework.md)。
- 询问持仓、观点是否改变或旧文章的适用性：读 [观点时间线](references/view-timeline.md)。
- 需要具体出处：查 [来源索引](references/source-index.md)，使用其中的来源编号读取原文。
- 维护或检验回答质量：读 [内容评估](references/evaluation.md)。

## 查证文章

项目根目录有 `jinjiancheng_knowledge_base.json`。实际可检索正文为375篇，日期范围 **2022-11-05—2026-04-29**。离线目录的更早文件名不等于已收录正文。日期使用库内 `publish_time`，不自行推定时区或精确交易日。

在项目根目录执行：

```bash
# 按关键词查全文，并补充与主题有关的已核对摘录
python3 jinjiancheng_grounding.py "中国平安"

# 阅读来源索引中的完整文章，无需模型 API
python3 jinjiancheng_grounding.py --source S04 --full

# 历史时点：只读取不晚于该日期的材料
python3 jinjiancheng_grounding.py "茅台" --as-of 2023-12-31
```

脚本位置是项目根目录；从本 skill 目录出发为 `../../../jinjiancheng_grounding.py`。不要假定宿主当前工作目录就在仓库。知识库及来源索引由脚本按自身位置加载。

来源编号指向 [sources.json](references/sources.json) 中的文章及连续原文摘录。它是精选核对材料，不是完整主题索引。关于“最后一次”“一直”“从不”的问题，必须继续搜索全库并核对账户、时间和后续行动。未找到后续记录时说“收录材料未找到后续更新”。

不要只看标题或文章开头。观点、反例、退出理由可能出现在后半段。关键词命中只用于找材料，不代表该材料足以支持答案。引用前阅读相关段落的上下文；需要时用 `--source … --full`。

若用户指定“截至某日”，先按日期筛选原文；参考文档中的后来结论仅用于定位材料，不得进入该历史时点的回答。先前对话中的未来信息也不能倒灌。文章发布时间与文中回顾的交易时间分开说明。

## 作答

先回答用户最关心的问题，再给必要的原文依据、判断条件和不确定性。简单问题无需展开全部投资流程。需要套用到用户处境时，区分原文、概括和分析推演。

历史事实注明文章标题与日期；有可用路径时附原文路径。引用只覆盖材料实际支持的主张。没有依据的价格、比例、个人持仓或“名言”不补写。

允许说不知道，也允许指出作者自述的局限。作者的收益、预测命中和交易记录属于文章自述，不能据此宣传已验证的成功率。
