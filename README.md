## 🆚 为什么选择Bedrock？

| 特性 | Bedrock | Anthropic API |
|------|---------|---------------|
| 价格 | 同价 | 同价 |
| 网络 | AWS内网（稳定） | 公网 |
| 计费 | 统一AWS账单 | 单独付费 |
| 权限 | IAM精细控制 | API Key |
| 区域 | 可选亚太（低延迟） | 固定 |
| 适合 | 已有AWS账号 | 独立使用 |

**推荐Bedrock的情况**：
- ✅ 你已经有AWS账号
- ✅ 需要IAM权限管理
- ✅ 想统一在AWS账单中管理
- ✅ 需要在EC2/Lambda上运行

详见：[Bedrock使用说明.md](Bedrock使用说明.md)

## 🚨 常见问题

### Q1: Bedrock API调用失败？

**错误**：`AccessDeniedException`

**解决**：
1. 进入AWS Console → Bedrock → Model access
2. 启用 Claude 3.5 Sonnet
3. 检查IAM权限

### Q2: 回答质量不够好？

**可能原因**：
- 问题过于宽泛
- 知识库中没有相关内容

**解决**：
- 问更具体的问题
- 先浏览文章库，了解有哪些话题

### Q3: 费用太高？

**省钱方案**：
```python
# 方案1：改用便宜的模型（Haiku，便宜10倍）
BEDROCK_MODEL_ID = 'anthropic.claude-3-haiku-20240307-v1:0'

# 方案2：减少上下文
articles = search_relevant_articles(question, kb, limit=2)  # 从3改成2

# 方案3：缓存常见问题的回答
```
